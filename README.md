# USDT ↔ FCFA Invoice Calculator

A single-file, fully offline invoice calculator for USDT/FCFA work: set the day's rate, convert in either direction, build itemized invoice lines and copy a plain-text summary. No dependencies, no network.

![Stack](https://img.shields.io/badge/stack-vanilla%20JS-c8f542) ![Deps](https://img.shields.io/badge/dependencies-0-c8f542)

## Features

- **Editable exchange rate** (FCFA per 1 USDT)
- **Two-way quick convert** with a swap button
- **Invoice lines** — item, quantity, unit price in USDT, per-line totals
- **Totals in both currencies** and a copyable invoice summary
- **Offline by design** — one HTML file, works with no connection

## Run it

Open `index.html`. That's it.
